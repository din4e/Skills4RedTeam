# Skills4RedTeam

面向红队操作人员的攻击性安全技能集合。

## 简介

本仓库收录了面向 Claude 技能系统的安全技能合集。每个技能是一个结构化的 `SKILL.md` 文件，为 Claude 注入针对特定攻击面的专业方法论 —— 从 SQL 注入到 Shellcode 编写，从 EDR 规避到漏洞利用开发、逆向工程、代码审计。

仓库同时收录社区开源的优秀安全技能推荐，形成覆盖攻击性安全、防御审计、漏洞研究等多领域的完整技能生态。
